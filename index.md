Complete HTML Template with Metadata
HTML
<!DOCTYPE html>
<html lang="en">
<head>
    <!-- 1. Character Encoding -->
    <meta charset="UTF-8">

    <!-- 2. Mobile Viewport Meta Tag -->
    <meta name="viewport" content="width=device-width, initial-scale=1.0">

    <!-- 3. Meaningful Page Title -->
    <title>My Awesome Project — Home</title>

    <!-- 4. Meta Description -->
    <meta name="description" content="Discover my updated web project featuring modern metadata, responsive design, and proper structure.">

    <!-- 5. Favicon Link -->
    <!-- Replace 'favicon.ico' or 'favicon.png' with the actual path to your favicon file -->
    <link rel="icon" type="image/x-icon" href="./images/favicon.ico">

    <!-- 6. CSS Stylesheet Link (Path Verification) -->
    <link rel="stylesheet" href="./css/style.css">
</head>
<body>

Step-by-Step Breakdown of the Metadata Code
If you need to explain your code for your submission, here is what each line does:

Character Encoding (<meta charset="UTF-8">): Ensures that your website supports universal characters, symbols, and emojis without displaying strange text artifacts.

Mobile Viewport (<meta name="viewport" content="width=device-width, initial-scale=1.0">): Tells mobile browsers to render the page at the device's actual width, making your design truly responsive.

Meaningful Title (<title>): Displays the title in the browser tab and helps search engines understand what your specific page is about.

Meta Description (<meta name="description" ...>): Provides a concise summary of the page content that often appears underneath your link in search engine results.

Favicon (<link rel="icon" ...>): Links a small icon to appear next to your page title in the browser tab. (Make sure you place an actual .ico or .png file in your project folder at the specified path).

CSS Link (<link rel="stylesheet" ...>): Correctly links your external stylesheet using a relative path so your styles load reliably.
